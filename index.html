ZappRagg — Sub-Millisecond Extractive RAG Engine
<5ms end-to-end · 84% cross-lingual Recall@5 · no LLM in the loop
▼
What it is

A 3-tier retrieval pipeline (FAISS IVF-SQ8, FP16 memory-mapped rescoring, ONNX INT8 extractive QA) that returns answers pulled directly from source text. Tested on the 14-language MSMARCO-XI benchmark and deployed on an Azure VM with hardware-aware ONNX dispatch across CPU, CUDA, and DirectML.

Where it helps in real life

Customer-support and internal-knowledge search where answers must be instant, cheap, and traceable to a source. With no generative model, it can't invent an answer, and it runs without per-query LLM costs. Multilingual support matters for Indian users searching in their own language.

LabelOps / ActiveLabelingSystem
Cuts labeling effort 60–80% · published on PyPI
▼
What it is

A human-in-the-loop annotation tool. Entropy-based sampling picks the images the model is least sure about, so people only label what matters, while a model retrains in the background and is hot-swapped in with zero downtime. Includes a FastAPI backend with token auth, dataset versioning, Ray/Docker retraining pipelines, and 85%+ test coverage.

Where it helps in real life

Labeling is the slowest and most expensive part of any vision project. Any team building a detector (defects on a factory line, crops, safety gear) can reach a usable model with far fewer hand-labeled images.
